# 🛒 Online Shop

A modern **frontend-only e-commerce website** built with vanilla HTML, CSS, and JavaScript.

This project simulates a real online shopping experience with product browsing, a shopping cart, and a responsive interface — all without a backend.

## 🚀 Features

* 🛍️ Browse products
* 🔎 Product search
* 🏷️ Product categories/filtering
* 🛒 Add products to cart
* ➕ Increase/decrease product quantity
* 🗑️ Remove products from cart
* 💰 Automatic cart total calculation
* 💾 Cart persistence with `localStorage`
* 📱 Fully responsive design
* 🎨 Modern UI
* ⚡ Vanilla JavaScript — no frameworks
* 🔐 Frontend-only checkout simulation

## 🛠️ Built With

* **HTML5** — Structure
* **CSS3** — Styling & responsive design
* **JavaScript (ES6+)** — Functionality & cart logic
* **LocalStorage API** — Saving cart data

## 🛒 How the Cart Works

Products are stored as JavaScript objects and rendered dynamically on the page.

When a user adds a product to the cart, the cart state is updated and stored in `localStorage`.

This allows the cart to remain available even after refreshing or reopening the page.

## ⚠️ No Backend

This project intentionally does **not** use a backend or database.

Therefore:

* No real user accounts
* No real authentication
* No real payments
* No server-side product management
* No real order processing

The checkout process is only a frontend simulation.
